# FrameLab Android 0.3.6

## 本轮更新

- 手机首页移除无作用的返回箭头；导出页返回编辑。
- 图库照片直接进入编辑，批量选择独立为选择模式，保留照片副本菜单。
- 编辑工具调整为水印／图片水印／画面／信息／模板。文字快捷编辑保留在水印面板和更多菜单内。
- 自定义 PNG/JPG/WebP 图片水印：原色、单色染色、不透明度、大小、旋转、平铺、水平与垂直位置、六个边缘对齐按钮。
- 改色保留透明度，不覆盖原素材；照片记录、历史、模板和模块复制保留图片水印设置。
- 中性炭灰与暖金强调色。编辑面板竖屏停靠下方，横屏停靠右侧，画布保留可见空间。
- 修正长内容换行、控件最小宽度和输入字号。旧桌面布局不变。

## 使用

直接覆盖安装同包名 APK，勿先卸载；建议先在设置中备份。
编辑照片 → 图片水印 → 导入图片水印。推荐使用透明 PNG；保留原色可随时撤销染色，底部参数区域可向上滚动。
位置按画幅比例保存；对齐计算包含旋转后的素材边界，但 PNG 文件自身透明留白属于素材的一部分。
单份素材限制20MB、1600万像素；这是水印素材限制，不是原照片分辨率限制。

## 验证与边界

自动测试49文件／380项通过，前端类型检查及生产构建通过。
Android 15 模拟器已验证透明PNG导入与染色、1200×800 PNG实际保存至相册、重启恢复素材与颜色。
360／375／393／430宽度下编辑页、水印、图片水印、模板容器未出现横向溢出；横屏863×360和系统字体1.3倍已检查。
这些不是vivo X100s本轮真机验收，也不代表所有复杂模板均已逐一视觉验收。

沿用既有离线架构、com.framelab.app包名与签名，版本码3006；不连接开发服务器。
本轮未改造大图分块原生导出、锁屏后台持续渲染、自选输出目录等尚未完整实现的能力。导出仍应保持前台，切后台按现有暂停／恢复逻辑处理。
