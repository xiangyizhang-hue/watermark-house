# FrameLab Android 0.3.5（个人版）

日期：2026-09-22。基于用户已在 vivo X100s 确认可用的 0.3.4 增量完善，不替换原有渲染引擎。

## 本次更新

- 设置 → 数据 → 管理备份：通过安卓系统文件选择器保存 ZIP，包含图库原图、虚拟副本、逐图编辑历史、撤销位置、快照、自定义模板及 Logo。
- 恢复前校验原图 SHA-256、文件大小、路径、版本及引用关系。恢复采用追加方式，重新生成标识，不覆盖现有作品。
- 原图和历史提交时同时保存待恢复素材记录；素材/模板存储失败可在设置重试，重启也会继续恢复。重复重试不会重复添加同批模板。
- 模板库支持 JSON 文件导入/导出，包含引用的自定义 Logo；拒绝缺失素材或不支持版本的模板。
- 修复旧模板保存流程丢弃自定义Logo的问题：手动Logo随模板，自动相机品牌仍随目标照片EXIF；兼容原有SVG/GIF等图片素材。
- 图库“编辑／更多”分开排列；模板删除增加确认；去掉无用英文装饰文字，文件名可点开查看完整信息。
- 横屏参数侧栏为画布预留空间，修复画布最小高度造成的底部裁切；文字快捷编辑改善大字体换行和完成按钮位置。
- 模板库关闭时不继续绘制缩略图，减少编辑期间不必要的渲染。

## 安装与数据

手机安装 `FrameLab-0.3.5-arm64-release.apk`。Android 12及以上，arm64-v8a，包名 `com.framelab.app`，版本码3005。

直接覆盖安装，**不要卸载旧版或清除数据**。沿用0.3.4已有签名，保留现有图库和模板。此个人版沿用已有开发证书，不宣称采用新生产证书；密钥不进入源码包。

离线资源随APK打包，不需要电脑或 localhost:5180。Windows桌面安装包及原有定制改动未替换。

## 备份注意

- 备份不包含已导出成片、未完成导出队列和应用偏好设置；相册成片由系统相册自行保管。
- 恢复是追加，不是覆盖。反复选择同一备份恢复会产生新的照片/模板副本。
- 写入或校验时保持应用打开；大图库需要足够存储空间。文件选择器取消不会开始恢复。
- 清单上限32MB（历史、快照和素材合计），每个原图解压上限1GB，额外保留64MB空间。超过限制明确报错，不静默漏数据。
- 备份包含照片与拍摄信息，未加密，请选择可信位置。失败时系统目录可能留下不完整文件，不要用它恢复。
- 卸载会删除应用私有原图与历史；请先将备份保存到应用之外的目录。
