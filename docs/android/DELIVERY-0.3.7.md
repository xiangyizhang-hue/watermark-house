# 0.3.7 色卡修复

## 原因

本地原图使用 asset URL。取色代码对所有本地图片调用只支持 JPEG 的 Rust 缩略解码器，却遗漏失败后的备用解码；PNG、WebP，以及无法被此解码器读取的 JPEG 返回空结果，导致色卡不显示和相关导出失败。错误缓存使普通重绘不再自动重试。

已在0.3.6 Android模拟器的PNG照片复现“无法读取照片像素，请重新提取”。

## 修复

保留JPEG快速缩略取色；失败后通过本地文件IPC读取同源Blob，使用缩小位图取色，使用后释放位图。不使用固定假色，不把原图asset直接画入画布导致跨域污染。
预览、重新提取、自动模板色卡及导出共用此读取入口。已有手动色卡仍保留；点击重新提取可恢复原图自动色。

新增PNG、WebP、异常JPEG备用解码及失败后重试回归测试。全部50个测试文件、384项测试通过；生产构建通过。

包名com.framelab.app，版本0.3.7／3007，签名沿用原版。覆盖安装，不要卸载旧版。旧版APK和源码归档保留。
本轮为取色修复，不改变UI布局、图库或模板格式。手机后台导出等原有边界保持不变。
