## 本轮修复

- Android release 缺少 custom-protocol 时构建直接失败，避免再次发出依赖开发服务器的包。
- 增加 npm run android:build:offline，显式开启离线协议并清除 devUrl；未运行完整 Android 构建，不能称为构建验收通过。
- 手机端忽略桌面启动模板偏好，避免与照片历史恢复竞争。
- 复位为无装饰通过单次提交记录；补测重启保留、原片信息保留及撤销恢复。
- 生命周期保存完成时若已有新编辑，状态保持待保存；同步存储异常可以提示并重试。
- 图片存储不可用时抛错，不再静默视为成功。
- 拒绝越界/小数队列游标、空配置和非法质量/倍率/时间戳。
- Android 相册写入失败直接上报，不再回退浏览器下载并伪装成功。
- 按 UI/UX 触控规范取消编辑页顶部品牌占位，保持工具可用空间，统一主要按钮至少 48px，表单输入 16px。未进行截图验收，不声称布局已通过。
